# Make the meaning visible

## Replace a process report with the result

Before:

> The runtime authorization boundary surfaces a stale-context disposition following source capture, preventing subsequent admitted execution.

After:

> The first import made Ada reject the next message. The task now recognizes its own imported changes and continues.

Keep operation IDs and implementation detail in the technical reference unless the reader needs them to act.

## Put the action first

Before:

> As part of the configuration workflow, users are able to navigate to the provider configuration section to establish access credentials.

After:

> Open Settings > Connections and add your API key.

## Keep the consequence beside the control

> Stop cancels future work. It cannot undo a message already sent.

That is easier to use than a separate page of generic warnings.

## Preserve a useful explanation

> Ada keeps the original message and its later corrections. It can update what it believes without rewriting what you said.

Short does not mean vague. Keep the mechanism that explains the behavior, then remove the ceremony around it.
