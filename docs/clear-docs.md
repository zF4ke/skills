# Clear docs

Use Clear docs to write or reorganize READMEs, setup guides, manuals and reference pages. It checks the writing against the product's actual behavior and separates current instructions from historical research.

```text
Use $clear-docs to rewrite this README around installation and everyday use. Check every command against the code.
```

For installation and updates, use the [shared guide](installing.md). The skill's entry point is [clear-docs/SKILL.md](../clear-docs/SKILL.md).

## Choose the work

| Request | Result |
| --- | --- |
| Refresh a README | A clear first action and links to focused guides. |
| Reorganize dense docs | Separate guides for learning, performing a task and looking up details. |
| Explain important behavior | Current controls, conditions and limits beside the action they affect. |
| Deliver a manual | Editable source, checked navigation and reviewed page renders. |

The skill includes [writing examples](../clear-docs/references/examples.md), [manual guidance](../clear-docs/references/manuals.md) and a [visual review process](../clear-docs/references/visual-verification.md). It does not generate a PDF just because Markdown documentation exists.

Use Personal UI alongside it when product presentation also needs the owner's visual preferences. Clear docs remains useful on its own for technical accuracy, structure and wording. [Validation notes](../clear-docs/references/validation.md) record its existing checks.
